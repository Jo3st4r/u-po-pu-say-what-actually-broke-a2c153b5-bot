## The error

> This worked in testing and broke in front of you. It has done this before, and it will do it again.

1 test passed, 0 users served, 3 times it lied: the error tells the brutal truth nobody writes in an error dialog — it worked in testing and broke in front of you — then admits it has done this before, and turns on the user with the promise it will do it again. It is funny because every developer has seen exactly this dialog, at exactly the worst moment, and the software knew it all along.
